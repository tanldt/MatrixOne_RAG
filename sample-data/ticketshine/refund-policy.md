# Refund Policy

## Delayed ticket orders

Refunds are allowed only when Ticketshine cannot deliver valid tickets before the event start time or when operations confirms the seller cannot fulfill the order.

## Customer requested refund while delivery is still expected

If delivery is still expected before the event, support should explain the current status, confirm monitoring, and avoid promising a refund unless the refund criteria are met.

## Required documentation

Support should cite the order timeline, seller status, customer messages, and operations notes before approving or denying a refund.
